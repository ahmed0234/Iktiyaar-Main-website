# Agents.md

## Project Vision

This project is not just a website. It is a visual experience crafted to feel modern, fluid, and alive. Every interaction should feel intentional. Every animation should feel smooth and meaningful. The goal is to create a premium digital presence that instantly builds trust and captures attention.

---

## Design System

### Core Theme

* Primary theme is **white and blue**
* White represents clarity, cleanliness, and space
* Blue represents trust, depth, and professionalism

### Visual Direction

* Minimal but not empty
* Modern and slightly futuristic
* High contrast where needed
* Soft gradients blended with clean surfaces

---

## UI Principles

### Glassmorphism

* Use subtle blur backgrounds with transparency
* Avoid overusing heavy blur
* Combine with soft borders and shadows
* Maintain readability at all times

### 3D Effects

* Use depth to create hierarchy and engagement
* Subtle perspective shifts on hover
* Layered elements to simulate real-world space
* Integrate Three.js elements where it adds value, not distraction

### Micro Interactions

* Every clickable element should respond
* Hover states must feel smooth and responsive
* Buttons should feel alive, not static
* Feedback should be instant and polished

---

## Animation Philosophy

### General Rules

* Animations must feel natural and smooth
* Avoid abrupt or robotic motion
* Use easing that mimics real-world physics

### Reveal Animations

* Elements should not just appear, they should **enter**
* Use fade + slight movement combinations
* Stagger animations for lists and sections
* Keep timing consistent across the site

### Scroll-Based Animations

* Sections should reveal progressively while scrolling
* Use parallax and depth effects carefully
* 3D scroll interactions should feel immersive, not overwhelming
* Maintain performance at all times

---

## Technology Stack

### Styling

* TailwindCSS is the foundation
* Use utility-first approach
* Extend Tailwind when needed for custom design tokens

### Components

* shadcn is used for base components
* Components should always be customized to match the design system
* Avoid default styling, everything should feel branded

### 3D and Advanced Effects

* Three.js is available for immersive visuals
* Use for hero sections, backgrounds, or interactive highlights
* Do not overload pages with heavy 3D scenes

---

## Performance Rules

* Optimize all animations for smooth performance
* Avoid unnecessary re-renders
* Lazy load heavy components
* Keep bundle size controlled
* Maintain fast initial load time

---

## UX Guidelines

* Keep navigation intuitive and simple
* Focus user attention using motion and spacing
* Avoid clutter at all costs
* Maintain clear call-to-action visibility
* Ensure accessibility is not compromised

---

## Code Standards

* Keep components reusable and modular
* Maintain clean folder structure
* Use meaningful naming conventions
* Avoid unnecessary complexity
* Write scalable and maintainable code

---

## Final Note

This project should feel premium, intentional, and slightly ahead of its time. The combination of clean design, smooth motion, and subtle 3D depth should create an experience that users remember, not just use.
